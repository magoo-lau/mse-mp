# 02 内容运营操作手册

> 建议角色：`mp_content`｜数据范围：本租户全部｜菜单：菜单配置、回复规则（完整），粉丝/消息/仪表盘（只读）。
> 定位：公众号内容的策划与执行——负责**自定义菜单**（编辑草稿、同步微信）与**自动回复规则**（关键词/关注/菜单点击的回复内容设计），让用户「点得动菜单、问得到回答」。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 自定义菜单策划、草稿编辑、同步到微信 | 菜单配置 |
| 自动回复规则设计（关键词/关注回复/菜单回复/兜底） | 回复规则 |
| 看粉丝涨跌与用户反馈，辅助内容决策 | 粉丝管理 / 消息事件（只读） |
| 看大盘趋势 | 仪表盘（只读） |

## 二、自定义菜单

> 路径：微信公众号 → **菜单配置**。页面顶部先选公众号；「可视化 / JSON」两种编辑模式随时切换。

### 2.1 可视化编辑（推荐）

1. 「**+ 一级菜单**」添加底部菜单（最多 **3** 个）；一级菜单内「**+ 子菜单**」添加二级项（每个一级下最多 **5** 个）。
2. 每个菜单项填写：**名称**（≤30 字）、**类型**（下拉），类型决定后续字段：
   - 「点击推事件 (click)」：填 **Key**——用户点它时微信推 click 事件，配合回复规则触发自动回复（Key 下拉与回复规则联动，可直接选用已有 Key）；
   - 「跳转网页 (view)」：填网页链接 URL；
   - 「小程序 (miniprogram)」：选本租户已接入的小程序 AppID 及路径；
   - 其余类型（下发素材 media_id、扫码推事件、系统拍照等）按界面提示填写对应字段。
3. 「上移 / 下移」调整排序，「删除」移除项。
4. 点「**保存草稿**」——注意：**保存草稿 ≠ 发布**，手机端此时看不到变化。

### 2.2 JSON 模式（高级）

切换「JSON」页签直接编辑与微信 `menu/create` 同构的 JSON，适合批量调整与高级用法；JSON 无法解析时保存会被拦截并提示先修正。

### 2.3 同步与核对

1. 草稿确认无误后点「**同步到微信**」→ 确认弹窗。
2. ✅ 成功标志：提示已同步；草稿状态变为「已同步」；手机端（关注该号的微信）取消关注再关注或稍候几分钟，即可看到新菜单。
3. 「**拉取线上**」：把微信线上菜单拉回页面与草稿比对（兼容 JSON/XML 两种返回、自动归一化）——核对线上实际生效内容用。
4. 「**删除线上**」：清空该号线上菜单（本地草稿保留），配合确认弹窗使用，慎点。

> 未认证公众号同步时提示 **48001（公众号未认证，无自定义菜单权限）**——先完成微信认证再同步。

## 三、自动回复规则

> 路径：微信公众号 → **回复规则**。点「**新建规则**」打开编辑框。

### 3.1 规则要素

| 要素 | 填法 |
| --- | --- |
| 公众号 | 本条规则挂在哪个号（必选） |
| 规则名 | 便于管理识别，如「欢迎语」「价格咨询」 |
| 匹配类型 | 关注 / 取关 / 菜单点击 / 任意消息 / 关键词精确 / 关键词包含 / 兜底 |
| 匹配值 | 「菜单点击」= 菜单按钮 Key（下拉可直接选）；「关键词包含/精确」= 关键词，多个用逗号、空格或竖线分隔（如 `价格,报价|多少钱`） |
| 回复类型 | 文本 / 图文 |
| 回复内容 | 文本直接填文字；图文逐条填**标题（必填）**、摘要、封面图 URL、原文链接 URL，最多 **8** 条 |
| 优先级 | 数字越大越先匹配（同类型内比较） |
| 启用 | 停用规则不参与匹配 |

### 3.2 匹配顺序（固定，设计规则前必读）

系统按 **关注 → 取关 → 菜单点击 → 任意消息 → 关键词精确 → 关键词包含 → 兜底** 的类型顺序匹配，先到先得；同类型内按优先级大者先。

设计要点：

- 「关注」回复做欢迎语；「取关」回复一般留空或不建（取关后用户收不到回复，建了也常无意义，按运营策略定）。
- 「任意消息」会拦截所有普通消息——**慎用**：它排在关键词规则之前，建了「任意消息」规则后关键词规则永远轮不到；要全量兜底应答请用「兜底」类型。
- 「关键词包含」对用户发来的文字做包含匹配，多关键词任一命中即触发。
- 每个号建议必配：关注欢迎语 + 兜底回复，避免用户消息石沉大海。

### 3.3 验证一条规则

1. 保存并确认规则「启用」。
2. 用微信向该公众号发一条命中消息（如规则关键词「价格」就发「价格多少」）。
3. 微信内应收到回复；到「消息事件」页找到这条记录，「已回复」列应为「是」，点「详情」可核对回复内容。

## 四、用只读数据辅助内容决策

- 「粉丝管理」：看关注/取关时间与关注场景（扫码关注的会记录场景），涨粉异常时结合近期内容复盘。
- 「消息事件」：看用户都在发什么——高频关键词就是关键词规则的候选；点详情核对现有规则命中情况。
- 「仪表盘」：今日消息数与 7 天趋势判断内容动作的引流效果。

## 五、运营注意事项

1. **保存草稿 ≠ 发布**：菜单改完必须「同步到微信」才对用户生效；同步后用「拉取线上」核对。
2. **菜单点击规则要成对**：新建 click 类型菜单项后，到「回复规则」建同 Key 的「菜单点击」规则，否则用户点了没反应。
3. **改 Key 要两边同步**：修改菜单 Key 后，旧 Key 的规则会失配——同步更新规则匹配值。
4. **图文链接用公网可访问地址**：封面图 URL 与原文链接必须是公网可打开的地址，微信内才能正常展示。
5. **规则先停用再改造**：调整生效中的规则前先「停用」，改好验证后再启用，避免半成品规则线上误回复。
