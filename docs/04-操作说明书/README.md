# 04 操作说明书 —— 总览与使用指南

> MSE-MP 微信公众号管理平台**分角色操作说明书**总览。每本手册面向一个业务岗位，讲清「这个岗位能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)。手册描述以当前系统实际界面为准。

| --- | --- | --- | --- |
| [01-公众号管理员](01-公众号管理员.md) | mp_admin | 本租户全部 | 账号接入、微信后台对接、凭据与连通性、Token 排查，全模块兜底 |
| [02-内容运营](02-内容运营.md) | mp_content | 本租户全部 | 自定义菜单策划与发布、自动回复规则与图文内容设计 |
| [03-客服专员](03-客服专员.md) | mp_service | 本租户全部 | 消息流水核查、粉丝档案查询、回复命中情况跟进 |

> 角色说明：系统**不预置**业务角色——由租户管理员在基座「组织管理 → 角色管理」按上表编码创建角色并勾选菜单/权限（授权清单见 [03-角色规划](../03-角色规划.md) 第四节），再授予员工。租户超管天然拥有全部权限。一个员工可兼多角色，权限取并集；所有人可见的菜单还受租户「套餐」勾选的上界约束。

## 二、进入系统

1. 用企业账号登录**基座门户**（浏览器访问门户地址）。
2. 登录后在左侧导航找到「**微信公众号**」分组目录，展开即见本系统全部页面：仪表盘、公众号管理、菜单配置、粉丝管理、消息事件、回复规则。菜单按你的角色授权显示——看不到某个菜单表示该角色未授权或套餐未包含。
3. 界面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，页面内不再单独登录。
4. 公众号相关页面均以**「公众号」下拉**为第一筛选条件——先选号，再看数据。

## 三、系统业务全景

```
管理员接入公众号（AppID/AppSecret/Token/EncodingAESKey）
  → 系统生成回调地址 → 在微信公众平台「服务器配置」填入并提交验证
  → 「测试」验证凭据 → Token 状态「有效」
用户侧（微信内）：
  关注 / 取关 / 扫码 → 粉丝档案自动维护（粉丝管理页可查）
  发消息 / 点菜单 → 消息事件流水落库（消息事件页可查）
      → 命中自动回复规则 → 微信内立即收到回复（文本/图文）
运营侧：
  菜单配置：编辑草稿 → 同步到微信 → 手机端菜单生效
  仪表盘：接入数 / 粉丝数 / 今日消息 / 启用规则 + 近 7 天趋势
```

## 四、通用操作（所有页面一致）

### 4.1 列表与筛选

- 筛选区在列表上方：文本框输入后按**回车**或点「查询」触发；下拉筛选（公众号、状态、类别等）**选中即生效**，点清除图标恢复全部。
- 列表分页显示（固定每页 10 条，翻页查看）；数据量大时请配合筛选缩小范围。

### 4.2 公众号选择

- 「菜单配置 / 粉丝管理 / 消息事件 / 回复规则」页面顶部都有「公众号」下拉（显示 `名称（AppID）`）。
- 不选即查**本租户全部公众号**的数据；要做针对某个号的操作（如编辑菜单），必须先选中该号。

### 4.3 复制

- 「接入配置」弹窗内的回调 URL、Token、EncodingAESKey 均有一键「复制」按钮——填入微信公众平台时逐项复制，**不要手抄**（43 位 AESKey 手抄极易出错）。

### 4.4 外观

深浅色模式与主题色跟随基座门户设置（门户右上角切换），页面自动跟随，无需单独设置。

## 五、状态字典速查（界面标签的准确含义）

| 业务对象 | 状态枚举 |
| --- | --- |
| 公众号账号 | 启用 / 停用（停用后不再处理该号回调推送） |
| 公众号类型 | 订阅号 / 服务号；另有「已认证」勾选标记 |
| 消息加密方式 | 明文模式 plain / 兼容模式 compatible / 安全模式 safe（与公众平台服务器配置一致） |
| Token 状态 | 有效（显示到期时间）/ 失败（显示错误码与原因，如 40125 密钥错误、48001 未认证无权限） |
| 菜单草稿 | 有改动（保存过但未同步）/ 已同步（与微信线上一致） |
| 粉丝 | 关注中 / 已取关；「资料不全」标记（未认证号拉不到粉丝资料） |
| 消息/事件 | 类别：事件 / 消息；类型：subscribe、subscribe_scan、unsubscribe、click、view、scan、location、text、image、voice、video、shortvideo、link |
| 消息已回复 | 是 / 否（命中规则并回复过 = 是；点开详情可看回复内容） |
| 回复规则 | 启用 / 停用（停用规则不参与匹配） |
| 匹配类型 | 关注 / 取关 / 菜单点击 / 任意消息 / 关键词精确 / 关键词包含 / 兜底 |
| 回复类型 | 文本 / 图文（图文最多 8 条） |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到「微信公众号」菜单 | 该角色未授权此菜单，或租户套餐未包含。联系租户管理员在「角色管理 / 套餐管理」检查。 |
| 公众平台「服务器配置」提交验证失败 | 逐项核对：回调 URL 是否为「接入配置」弹窗原样复制的地址、Token 是否与系统一致、服务器是否公网可达（开发环境需内网穿透，见 [05-配置手册](../05-配置手册-零基础版.md)）。 |
| 点「测试」提示 40125 | AppSecret 不正确——去公众平台「设置与开发-基本配置」重新查看并录入（录入后系统加密保存、不再回显）。 |
| 点「测试」或同步菜单提示 48001 | 公众号**未认证**，无该接口权限：自定义菜单、粉丝资料等接口需要认证号；账号需先通过微信认证。 |
| Token 状态列显示「失败」后一直不恢复 | 失败原因会展示在列表与详情中：40125=密钥错误（重新录入 AppSecret）、48001=未认证（先认证）；修正凭据后点「测试」，通过即恢复。 |
| 用户发了消息但没收到自动回复 | 依次检查：「回复规则」页是否有**启用**的规则能命中该消息（匹配类型/匹配值是否写对）→ 消息事件页打开该消息详情看「已回复」列——未回复即未命中规则，调整规则。 |
| 用户点菜单没有回复 | 菜单按钮类型须为「点击推事件 (click)」且有 Key，且回复规则页存在匹配类型=「菜单点击」、匹配值=该 Key 的启用规则（规则编辑框的 Key 下拉可直接选）。 |
| 粉丝页资料是空的/标「资料不全」 | 未认证公众号拉不到粉丝昵称头像等资料，属正常边界；认证后新进来的粉丝会带全资料。 |
| 菜单同步成功但手机上看不到 | 微信菜单在部分客户端有缓存：取消关注再关注、或稍等几分钟再看；确认同步的是当前编辑的号。 |
| 同一条消息会不会重复入库 | 不会：系统按幂等键去重，微信对同一推送的重试（最多 3 次）只产生一条记录，且回复内容复用缓存、不会重复回复用户。 |
| 列表里看不到别的租户的公众号 | 数据按租户隔离，属正常设计；且 AppID 全局唯一，一个 AppID 只能被一个租户接入。 |

## 七、阅读建议

- 新岗位上手：先读本手册第二节、第三节建立全局认识，再读对应角色手册的「典型流程」。
- 遇到具体按钮/字段疑问：查角色手册的「页面操作」小节，按钮文字与界面一致，可直接对照。
- 「为什么回了/没回这条消息」：永远从「消息事件 → 详情」开始排查（幂等键、载荷、回复缓存都在详情里）。
