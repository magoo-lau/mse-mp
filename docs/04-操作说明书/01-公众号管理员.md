# 01 公众号管理员操作手册

> 建议角色：`mp_admin`｜数据范围：本租户全部｜菜单：「微信公众号」分组下全部页面。
> 定位：公众号业务域的管理员——负责**账号接入**（把公众号接进平台）、**微信后台对接**（服务器配置）、**凭据与连通性维护**（凭据加密保存、连通性测试、Token 状态排查），并对全部页面拥有完整操作权限。**不负责**基座侧的用户/角色/套餐管理（那是租户管理员的事）。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 接入公众号、维护凭据、启停与删除 | 公众号管理 |
| 微信公众平台「服务器配置」对接（回调 URL / Token / EncodingAESKey） | 公众号管理 → 接入配置 |
| 凭据连通性验证与 Token 状态排查 | 公众号管理 → 测试 / Token 状态列 |
| 各业务域疑难操作兜底（菜单/规则/粉丝/消息全量权限） | 全部页面 |
| 运营大盘查看（接入数/粉丝数/今日消息/趋势） | 仪表盘 |

## 二、接入一个公众号（核心流程）

> 路径：微信公众号 → **公众号管理**。以下每步都有「✅ 成功标志」。

### 第 1 步：在微信公众平台准备四样东西

登录你自己的微信公众平台（mp.weixin.qq.com）→「设置与开发 → 基本配置」，准备：

1. **AppID**（开发者 ID，wx 开头）；
2. **AppSecret**（开发者密码，点「重置」可查看——请先记下再录入）;
3. **服务器配置 Token**（可自定义，3-32 位字母数字）；
4. **消息加密密钥 EncodingAESKey**（43 位随机串，点「随机生成」可获取）。

同时确认公众号**类型**（订阅号/服务号）与**是否已微信认证**——未认证号无法使用自定义菜单、粉丝资料等接口（48001）。

### 第 2 步：录入系统

1. 「公众号管理」页点「**接入公众号**」。
2. 填写：名称（必填）、AppID（必填，wx 开头）、类型、是否已认证、AppSecret（必填）、Token（必填）、EncodingAESKey（必填）、消息加密方式、备注。
3. 点「保存」。

✅ 成功标志：列表出现新行，AppSecret/Token/AESKey **不回显**（系统已 AES-256-GCM 加密落库）。

> 要点：**AppID 全局唯一**——同一 AppID 全平台只能接入一次（含其他租户），重复会被拒绝；AppID 录入后**不可修改**，填错只能删除重接。

### 第 3 步：回填微信公众平台服务器配置

1. 列表行内点「**接入配置**」。
2. 逐项点「复制」：**回调 URL**（形如 `https://<你的域名>/api/mp/callback/<AppID>`）、**Token**、**EncodingAESKey**。
3. 到公众平台「基本配置 → 服务器配置 → 修改配置」，把三项原样粘贴；「消息加解密方式」选择与录入时一致的模式（明文/兼容/安全）。
4. 点公众平台「**提交**」——公众平台会向回调 URL 发一次验证请求，系统自动应答。

✅ 成功标志：公众平台提示「验证成功」并显示服务器配置已启用。

> 要点：开发/内网环境没有公网地址时，先用内网穿透工具把公网 HTTPS 域名映射到本系统（见 [05-配置手册](../05-配置手册-零基础版.md) 第六节）。

### 第 4 步：连通性测试

1. 回到列表，行内点「**测试**」——系统会真实调用微信 access_token 接口验证凭据。
2. ✅ 成功标志：提示测试通过；列表「Token 状态」列显示「有效」及到期时间。

失败对照：**40125**=AppSecret 不正确（重新录入）；**48001**=未认证无权限（先做微信认证）；其他错误码按提示信息处理。

## 三、日常维护

### 3.1 Token 状态巡检

- 「Token 状态」列即该号 access_token 的健康度：系统会**过期前 5 分钟自动预刷新**，正常情况始终保持「有效」；同一时刻多个请求并发刷新也已串行化，不会打爆微信配额。
- 显示「失败」时鼠标悬停/点击查看错误码：40125=密钥错误、48001=能力未开放等；修正凭据（编辑 → 留空不改、只填要改的项）后再点「测试」验证。
- 凭据一旦变更保存，系统自动清空旧 token 缓存，无需手工干预。

### 3.2 编辑与启停

- 「**编辑**」：修改名称/类型/认证标记/加密方式/备注；AppSecret、Token、EncodingAESKey **留空 = 保持原值**，只填需要更换的项。
- 「**启用/停用**」：停用后系统不再处理该号的微信回调推送（粉丝消息不再进来），历史数据保留；重新启用即恢复。
- 「**删除**」：逻辑删除，页面不再显示；同 AppID 之后也不可再次接入。删除前确认该号确已停用。

### 3.3 换号/换密钥场景

| 场景 | 操作 |
| --- | --- |
| AppSecret 在公众平台被重置 | 编辑该号 → 填新 AppSecret → 保存 → 点「测试」确认 |
| 服务器配置 Token/AESKey 更换 | 编辑对应项 + 同步更新公众平台服务器配置（两边必须一致）→ 观察下一条消息正常入库 |
| 公众号停用不再运营 | 停用（保留数据）；确要清除则删除 |

## 四、仪表盘（运营大盘）

> 路径：微信公众号 → **仪表盘**。

- 四张统计卡：接入公众号数、关注粉丝数、今日消息/事件数、启用中规则数。
- 「近 7 天入站趋势」：事件/消息双线柱状图，观察涨跌与异常（如某天消息骤降，先查 Token 状态是否失败）。
- 「最近消息/事件」：最近 10 条流水速览，点进「消息事件」页可看详情。

## 五、管理员注意事项

1. **凭据安全红线**：AppSecret/Token/AESKey 加密保存、页面不回显；「接入配置」弹窗能看到明文是**唯一**回显入口（需要 Token/AESKey 填公众平台时使用），不要截图外传；AppSecret 忘记时去公众平台重置再录入。
2. **加密方式两端一致**：系统内选的「消息加密方式」必须与公众平台服务器配置的「消息加解密方式」一致，否则回调验签/解密失败、消息进不来。
3. **接入顺序不可颠倒**：先在系统录入凭据，再回填公众平台服务器配置——公众平台提交验证时系统必须已有该号的 Token 才能应答通过。
4. **停用优于删除**：公众号暂停运营用「停用」保留粉丝与消息历史；删除不可逆（同 AppID 不能重接）。
5. **多号运维**：每个号独立 Token 状态与菜单草稿，排查问题先在页面顶部「公众号」下拉锁定具体号。
