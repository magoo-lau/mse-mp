# 02 权限规划 —— 子应用注册、页面菜单与权限点

> mse-mp 的菜单与权限点设计。功能点含义见 [01-功能规划](01-功能规划.md)，角色授权见 [03-角色规划](03-角色规划.md)。
> **与 mse-mes 规划文档不同：本文所有 id 均为已落地的真实值**，转录自 `mp-service/src/main/resources/db/mysql/V20261001_01_mp__mp_base.sql`（`-- mse-target: base`，随 jar 由 starter-bridge 推送 mse-system 自动应用），号段已登记 `zcode-plugin/plugins/mse-dev/references/alloc-tables.md`。

## 一、规划原则（基座 RBAC 模型）

1. **三张全局表，一条链路**：`sys_micro_app`（子应用注册）→ `sys_menu`（导航菜单）→ `sys_permission`（权限点）；授权链 `sys_user → sys_user_role → sys_role → sys_role_menu / sys_role_permission`。
2. **sys_menu.type**：1=目录（本工程仅 430 一个分组目录）、3=子应用页面菜单（`micro_name='mp'` 关联子应用、`path` 为子应用内部路由）。`menu_scope=2` 租户端——mp 全部菜单为租户端，不涉及平台端。
3. **权限点必须挂靠页面菜单**：`sys_permission.menu_id` 指向本工程 type=3 页面菜单，才参与角色授权分组与**租户套餐裁剪**（`sys_tenant_package.menu_ids` 圈定菜单 → 隐含圈定挂靠的权限点）；本工程无 `menu_id=NULL` 的通用权限（早期安装的 NULL 权限点由脚本内条件 UPDATE 幂等补挂）。
4. **权限码格式**：`mp:<模块>:<动作>`，动作小写动词（list/save/delete），与仓库 `oa:form:list` / `mes:order:list` 等风格一致；权限点 `module='mp'`。
5. **前端按钮控制**：子应用内用 `v-permission` 指令按权限码显隐按钮（模板已内置 `mp-ui/src/directives/permission.ts`）；后端控制器以 `@SaCheckPermission`（租户登录态）逐端点把守，两者权限码一一对应。
6. **落库方式**：随 jar 的幂等版本化脚本（全段 `NOT EXISTS` 判重，可重复执行）由 starter-bridge 自动推送 mse-system 按 `mse_mp_schema_history` 分册账本应用——**免手工执行、不把 SQL 种子写进框架区**；已应用脚本不再修改（改动报 checksum 冲突），变更一律新增版本文件。

## 五、编码规范与续增纪律

1. **权限码**：`mp:<模块>:<动作>`；查询类一律 `list`，写操作按语义动词（save/delete）；粉丝与消息为只读页面，各只有一个 `list` 码。
2. **号段**：6xxx 段归 mp（alloc-tables.md 登记），已用满 6001-6011；**后续新增权限点从 61xx 顺延**，用前在 alloc-tables.md 登记确认无冲突。
3. **菜单号段**：430-436 已登记归 mp；新增页面从 437 起顺延（438+ 需先查 alloc-tables.md——相邻段 440-447 归 data、450-455 归 open，注意不要越界）。
4. **后端权限码唯一事实源**：控制器 `@SaCheckPermission` 上的码即权威口径；前端 `v-permission` 与权限点种子必须与之对齐，避免「控制器要求但种子缺失」的 403（mse-mes 曾发生漏播，新增码时三处同查）。

## 六、套餐裁剪与网关白名单

1. **租户套餐**：mp 页面菜单（431-436）需在平台端「套餐管理」勾选后才对租户可见；租户管理员拿到的是「套餐域内全量权限码」，裁剪对管理员同样生效。未配置页面菜单的中间状态会退化为单菜单项渲染，建议 431-436 一次配齐。
2. **网关白名单**：`/mp/callback/**` 已列入 `mse.gateway.ignore-urls`（微信回调无用户会话，以下游微信签名验签替代登录态；细粒度权限仍由下游 `@SaCheckPermission` 把守）。注意 Spring list 属性整体替换——调整白名单时须全量列出既有条目。
3. **匿名端点仅回调两个**：`GET/POST /mp/callback/{appId}`，其余 `/mp/**` 端点全部要求租户登录态 + 权限码。
